# 数据获取与恢复

GitHub 仓库保存代码及数据格式说明。真实 SEM 数据、训练配对缓存和本地测试照片不上传。当前没有公开下载地址，请向仓库维护者获取数据包。可以将数据包保存在实验室 NAS 或独立文件存储中，再解压到下列位置。

## 不依赖真实数据的代码检查

在项目根目录安装依赖后执行：

```powershell
python -m unittest discover -s tests -v
```

测试在临时目录中生成所需样本，不需要下载真实数据或预训练权重。历史四类掩膜流程的合成示例可通过以下命令生成，合成数据仅用于验证代码流程：

```powershell
python -m dsa demo-data --out data/demo --groups 18 --cells-per-group 12
```

## 真实数据的目录

```text
data/
├── 2D RE R25 RH32 提取-WZY-20261122/  原始 TIFF，保留倍率与分辨率目录
├── 2D_RE_R25_RH32_统一200nm_256/
│   ├── 2孔/                        单元 PNG
│   ├── 3孔/                        单元 PNG
│   ├── 统一比例尺单元清单.csv        裁剪来源、标定与有效区域
│   └── 整理说明.md
└── sem_pairs_256/
    ├── pairs.csv                   配对清单与划分
    ├── paired_pixels.npy           按清单索引存储的像素缓存
    ├── templates/                  填实孔后的白腔体模板 PNG
    └── examples/                   配对可视化，仅供核对
```

单元统一覆盖 200 nm × 200 nm，输出为 256 × 256，标定为 0.78125 nm/px。原图上采样到统一网格不会提高原始成像分辨率。

## 配对缓存的约定

当前缓存是 `uint8` 类型的 `(14244, 3, 256, 256)` 数组，各通道为：

1. 填实小孔后的二值模板，0 为外部，255 为内部。
2. 按 ±24 nm 截断、映射至 0～255 的有符号距离图。加载时恢复到 −1～1。
3. 同一单元、同一网格的原始 SEM 灰度标签。

清单的 `index` 必须对应数组第一维。主要字段包括 `cell_id`、`group_id`、`label`、`split`、`template_path`、`label_image_path` 以及有效区域 `valid_x0`、`valid_y0`、`valid_x1`、`valid_y1`。两孔类别编码为 0，三孔为 1，待复核样本不计入分类指标。具体读取和校验以 [common.py](../dsa/training/common.py) 为准。

同一物理点位的跨倍率和重复拍摄必须属于同一个集合，保持数据包内的既定划分。清单和像素缓存应作为同一版本一起保存，不能分别替换。

## 在另一台电脑上重新生成配对

清单中可能包含原维护电脑的绝对路径。若需要重新读取灰度标签、生成配对或运行会访问这些路径的旧实验，应在新电脑的项目根目录重新生成清单与缓存：

```powershell
python -m dsa.preprocessing.pairs --raw 'data/2D RE R25 RH32 提取-WZY-20261122' --images 'data/2D_RE_R25_RH32_统一200nm_256' --out data/sem_pairs_256_new
```

生成后将训练 JSON 中的 `pairs` 改为 `data/sem_pairs_256_new`。为保留原版本，使用新的输出目录。项目目前要求输入已经完成 200 nm 裁剪的单元数据；原始阵列 TIFF 本身不能直接替代单元标签目录。

每次共享数据包时，建议附上版本名称、采集点位范围、清单校验值和标定说明。下载地址和权限由维护者单独管理，Git 仓库中不保存访问令牌。
